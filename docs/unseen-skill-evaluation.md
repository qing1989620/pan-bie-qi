# 输入开源 Skill 后能评出什么

输入一条公开链接，服务定位到具体的 `SKILL.md`，尽量固定提交并取得包清单。报告提取用途、声明的能力、适用边界和依赖。可以核对的质量问题包括包内资源链接失效、Python 语法错误和受支持的命令与参数声明不一致。每个问题展示原文行号和检查范围。取得的清单不完整时，缺失资源保留待核对。

功能正确性和采用收益各有度量。判别器以固定任务上的独立产物验收和版本匹配的配对成绩支持这两类结论。页面新增 NVIDIA 公开报告对照，有无 Skill 两组都显示，并附任务集指纹和原报告。新 Skill 尚无相应功能证据时，报告继续给出可核查的包质量结果和待验证功能。

在本轮 79 个公开包中，37 个含受支持的包内引用，共找到 167 个引用目标，完整清单中的 167 个都能定位。对 37 个包各在实验清单中移除一个已存在的目标，判别器在 37/37 个完整清单上指出缺失。在同样的 37 个样本中，将清单标记为不完整后，各项都保留待核对。原仓库未改动。此项验证覆盖字面链接和清单证据的判定。

## 扩展实验

扩展到 113 个 Skill、43 个产品组，加入新的评估器版本。报告采用产品家族留出，并另用旧版训练，在 27 个来自新版本和新家族的 Skill 上测试。各方法仅使用同一份说明材料。网页的 16 个量表条目用于配对 Ridge 和 Extra Trees。另做同算法删掉这 16 个特征的测试。

| 目标 | 分组留出八近邻 | 分组留出选模 | 版本外八近邻 | 版本外选模 |
| --- | ---: | ---: | ---: | ---: |
| 有 Skill 正确性 | 15.90 | 12.29 | 19.02 | 13.43 |
| 正确性净增益 | 14.95 | 16.15 | 17.14 | 17.14 |
| 有 Skill 任务效果 | 17.52 | 14.72 | 21.16 | 17.25 |
| 任务效果净增益 | 13.82 | 13.33 | 18.98 | 18.42 |

各值为绝对误差的均值，单位为百分点。按组重采样时，第一行的选模减八近邻差值区间在分组留出为 [−6.71, −0.47]，在版本外为 [−8.66, −2.03]。版本外的中位数基线在两项绝对分上误差最低。分组正确性净增益的误差上升，Spearman 从 0.443 降到 0.118。文档预测目前保留为离线研究。

固定 Extra Trees 及训练和测试样本，加入分项特征后，正确性绝对误差在分组留出由 11.92 降到 11.07，在版本外由 13.25 降到 10.80。完整对照包含九种结果、消融、按组区间和逐 Skill 预测。[扩展实验数据](results/skill-assessment-training.json)

## 最接近的公开方法

| 方法 | 其评估对象 | 本仓库已完成的对照 |
| --- | --- | --- |
| SkillCT | 输入新 Skill 的说明，估计九维质量。六个需估计的维度在原文对照中 MAE 为 0.064。 | 复用 TF-IDF、余弦加权、Top-8 公式。以独立公开档案测试加载得分和净增益。尚未取得原逐 Skill 标签。 |
| SkillAudit | 输入 Skill 包，生成能力对齐任务，沙箱配对运行，得出效用、成本与安全结果。 | 已复算固定档案中的 1,277 个技能环境分，测量回退检出和点估计误差。有共同原始记录的比较见单独实验。 |
| NVIDIA SkillEvaluator（ACES） | 对 Skill 做静态核查和有无 Skill 的实际运行比较，报告分任务效果和收益。 | 使用作者固定快照中的逐 Skill 公开结果作为本轮标签。接口可回查所读版本对应的报告。 |
| OpenSkillEval | 在五类任务中比较社区 Skill，对照模型和宿主。 | 核对公开研究的任务范围。 |

论文与数据来源见 [SkillCT 表 6](https://arxiv.org/html/2610.38147v1#S5.SS9)、[SkillAudit](https://arxiv.org/abs/2606.22613v1)、[SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)、[NVIDIA 固定成绩](https://github.com/NVIDIA/skills/blob/252ba53487b73eaafbfcccf3e750c7b350b93db9/benchmarks.json)、[OpenSkillEval](https://aclanthology.org/2026.findings-emnlp.1554/) 和[前期回退复算](evaluation.md)。

## 留出组实验

从 NVIDIA 固定提交读取 `benchmarks.json` 和各 Skill 的 `SKILL.md`。过滤到官方评估器 1.5.6、Codex、k8s-sandbox，要求至少三项任务和正确性及任务效果的两组得分。选择技术产品范围及相应筛选逻辑见脚本。最终有 **79 个 Skill，31 个产品组**。同一产品组和跨组的高度近重复说明始终留在同一折中。近重复使用五词片段的 Jaccard 相似度，阈值 0.80。

所有方法在每折只用同样的训练项。训练中位数是常数对照。八近邻按 SkillCT 公式计算，IDF 只从训练项确定。结构回归利用说明长度、标题、步骤、资源、验收和限制等 15 个特征。融合在训练集内部按组产生预测，针对每个目标选择三种方法的凸组合。最后将这个组合用于外层的未见组。输入特征来自名称、用途和说明正文。官方配对成绩仅用于训练标签和留出验收。

| 预测目标 | 训练中位数 | SkillCT 八近邻移植 | 结构回归 | 分组校准融合 |
| --- | ---: | ---: | ---: | ---: |
| 有 Skill 的正确性 | 13.53 | 14.86 | 13.19 | **12.94** |
| 正确性净增益 | 16.98 | **15.21** | 16.31 | 16.30 |
| 有 Skill 的任务效果 | 17.58 | 17.20 | **17.02** | 17.63 |
| 任务效果净增益 | 12.18 | **11.44** | 14.50 | 11.90 |

表中是留出样本的 MAE，单位为百分点。正确性绝对得分的融合误差低 1.92 个百分点，与八近邻的差值在产品组重采样下 95% 区间为 **[−4.30, +0.49]**。Spearman 相关从 **0.132** 变为 **−0.090**。正确性增益误差高 **1.09** 个百分点，按同法估计的区间为 **[+0.26, +2.11]**。这些是固定留出预测上的描述性区间。融合对绝对正确性的经验区间命中 **88.6%**，平均宽 **42.1** 个百分点。

因此，当前证据支持测试过的包检规则和带来源的实测结论。单条说明预测的排名与增益精度仍有限，当前产品的功能评级使用实测。公开数据来自同一技术产品目录，原始任务和分数来自作者，亦可能受测评器偏差影响。可以核对发布快照中的 Skill 字节指纹和评测任务指纹。评测档案没有逐次运行的说明字节指纹。实验成绩只解释本次同数据比较。

