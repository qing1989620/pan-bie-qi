# 真实任务的改前改后验收

**测试日期** 2026-11-24。**对照** v1.0.0（`b1e4bec`）与 v1.1.0。

测试从网页粘贴一个真实公开 Skill 链接开始，目标是提取[这份中文双栏论文](skill-discriminator-paper.pdf)第 4 页的表 6。用从研究汇总数据独立生成的[参考 CSV](examples/paper-table-6.csv)逐行逐格核对。对照输入包括带竖线的网格表，以及把原论文页转换成无文字层的图像 PDF。浏览器验收另使用已登记的工位标签 Skill 检查历史实测误读。公开说明固定在 [Anthropic PDF Skill 提交 `e4bb5d9`](https://github.com/anthropics/skills/blob/e4bb5d960d87126ff3b3a8af1a104b7db67560ba/skills/pdf/SKILL.md)。

| 验收点 | v1.0.0 | v1.1.0 |
| --- | --- | --- |
| 工位 Skill 填入无关 PDF 任务 | 第一屏仍呈现该版本的历史结论 | 第一屏显示「当前任务待验证」，历史实测可展开 |
| 真实 PDF Skill 的表格任务 | 可读取 12 个文件，效果待验证 | 同版本仍显示效果待验证，并给出源文档中的工具依据及试跑入口 |
| 扫描输入及语言依赖 | 任务注明无文字层，报告没有相关预检 | 显示本机 PATH 的 Tesseract 状态及目标环境语言包待核对 |
| 在网页上传真实论文并交付 CSV | 文档检查不接受这个 PDF | 第 4 页当场提取，4/4 行及 16/16 个数据格与参考一致 |

同样的 12 项浏览器验收要求由 **8/12** 提升至 **12/12**。新增五项验证覆盖 CSV 下载、错误参考、无参考、扫描件回退和网格表正例，一并通过。软件自动化测试 **120 项通过**。上述计数针对本轮场景和验收项。

## 实际产物结果

| 输入 | 公开文档的默认 `extract_tables()` 直接试跑 | v1.1.0 网页试跑 |
| --- | --- | --- |
| 论文表 6，双栏且表格无竖线 | 0/4 行，0/16 数据格 | 识别网格失败后按版面回退，4/4 行，16/16 数据格 |
| 带竖线网格对照 | 4/4 行，16/16 数据格 | 网格识别，4/4 行，16/16 数据格 |
| 同一论文页的扫描图像对照 | 未提取到记录 | 明确返回 `needs_ocr`，无 CSV 结果 |

实际 PDF 提取的 CSV 与参考内容一致。把参考里的 `319` 改成 `320`，页面显示 15/16 格一致，并指出「SkillAudit 发布增益」行的「前排改善」列。移除参考后仍可提取，结果标记数值待核对。实测结果用本地解析器产生，原 Skill 的模型配对增益仍待另测。扫描件 OCR 和更复杂的跨页、合并单元格版式仍待验证。

## 复跑

启动 Demo，在「PDF 试跑」上传[论文](skill-discriminator-paper.pdf)与[参考](examples/paper-table-6.csv)，页码选择 4。软件测试中的 `test_pdf_table.py` 使用相同 PDF 和 CSV，也包含改错参考、去掉参考和纯图像输入的检查。运行 `python -m pytest -q` 可复核。
